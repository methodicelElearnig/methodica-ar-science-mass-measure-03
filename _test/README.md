# `_test/` — אורקל רגרסיה headless

**לא נפרס.** התיקייה הזאת היא כלי פיתוח בלבד ואין לכלול אותה בחבילת השחרור.

## מה זה בודק

`verify-report.js` טוען את `index.html`, `script.js` וכל `unit-js/*.js`
**האמיתיים** של ששת הסינים ב-jsdom, מריץ את תגי ה-script בסדר המסמך מהדיסק,
ומאמת ~1,335 טענות. הוא לא קורא לקוד — הוא מריץ אותו.

⚠️ **חוזה הנכסים (asset contract).** jsdom לעולם לא מושך גיליונות סגנון, תמונות
או וידאו — הוא מריץ רק תגי `<script src>`. עד 2026-09-07 היה אפשר להעביר את כל
הנכסים ביחידה בלי לשבור אף טענה. עכשיו כל הפניה לנכס ב-html/js/css נבדקת מול
הדיסק, **כולל התאמת רישיות** — `fs.existsSync` לבדו לא מספיק, כי Windows אדיש לרישיות
וה-CDN לא. זה מה ששומר על `assets/Video/` של סין 06.

## הרצה

jsdom אינו בריפו ואין `package.json`. **אין להתקין אותו בתוך תיקיית הפרויקט**:
היא יושבת ב-OneDrive מסונכרן, ו-`node_modules` של jsdom הוא כ-26MB שיסונכרנו
לחינם. להתקין בתיקייה חיצונית ולהצביע עליה עם `NODE_PATH`:

```bash
# פעם אחת, בתיקייה כלשהי מחוץ ל-OneDrive:
mkdir -p /tmp/lomda-test && cd /tmp/lomda-test && npm install jsdom

# ואז, מתיקיית הפרויקט:
NODE_PATH=/tmp/lomda-test/node_modules node _test/verify-report.js
```

יציאה 0 = הכול עבר. כשל מודפס כרשימה בסוף. ניתן גם להעביר נתיב בסיס אחר
כארגומנט ראשון; בלעדיו ההרנס מניח את תיקיית האב שלו.

> ⚠️ אם בכל זאת מתקינים מקומית — להתקין את כל החבילות ב**פקודה אחת**.
> `npm install X --no-save` בתיקייה בלי `package.json` עלול **להסיר** חבילה
> שהותקנה קודם באותה תיקייה; מלכודת שתועדה בסעיף 15 של
> `סיכום-תהליך-בניית-הלומדה.md`. `node_modules/` מסונן ב-`.gitignore`.

## שני דברים שה-jsdom לא יכול לכסות

1. **מראה.** ההרנס בודק קלאסים, טקסט ודגלי `disabled` — לא פיקסלים. אימות
   חזותי של המודאל דורש דפדפן אמיתי.
2. **`HTMLMediaElement`.** jsdom לא מממש `load()`/`play()`, ו-`play()` מחזיר
   `undefined` — כלומר `video.play().catch(...)` שבסינים 02/05/06 זורק.
   ההרנס מחליף את שלושתם בחוזה של הדפדפן, כדי לבדוק את מסלול הקוד האמיתי
   במקום פער של jsdom.

הכשל הזה עצמו הוא שגילה למה `unit-js/90-boot.js` חייב להיות תג script **נפרד**
ולא כמה שורות בתחתית `script.js`: זריקה ברמת top-level ב-`script.js` מפילה את
שאר אותו קובץ, ומודאל הדיווח לא היה מאותחל בכלל — בשקט.

## מה עדיין לא מכוסה

- **`answered` / `completed` על תשובות אמיתיות.** הדיווחיות עצמה עוד לא
  מחווטת (שלבים 2–3, חסומים על המטא-דאטה). כשהיא תחווט, יש להוסיף כאן sweep
  שמדפיס את יומן ה-statements כרשימה מנורמלת וניתנת ל-diff מול baseline שמור.
- **הרצה מול Kata אמיתי** עם `?slxapi` + `?registration`. stubs מוכיחים צורת
  payload, לא הגעה בפועל.
